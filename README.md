## 👋 关于我

这里是 **明宇**，也可以叫我 **小明 / XMing** 嗷～

计算机科学背景，目前主要在 **软件开发、Android / Linux、嵌入式与网络设备、Web / Cloud、AI 应用** 这些方向来回横跳。

所以这里既有正常的软件项目，也会出现 Android 内核、TWRP、OpenWrt、Cloudflare、NFC、智能设备，以及一些突然冒出来的小工具。
